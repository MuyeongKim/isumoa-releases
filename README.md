# <img src="assets/isumoa-repository-icon.png" width="40" height="40" alt=""> 이수모아 Windows 배포판

**법정교육 이수증을 모아 검수하고, 직원별 이수 현황과 기관 제출 자료를 만드는 Windows 프로그램입니다.**

EXE로 설치하면 필요한 실행 환경과 OCR 구성요소가 함께 설치됩니다. 수료증 판독·업무 자료 보관은 사용하는 PC에서 이루어지고, 화면은 Edge·Chrome 같은 브라우저에서 열립니다.

**GitHub 로그인 없이 다운로드**할 수 있습니다. **Windows 10·11 64비트**, 설치 시 디스크 여유 공간 **2GB 이상**이 필요하며 자료가 쌓이면 추가 공간이 필요합니다.

설치 파일은 이 저장소의 **GitHub Releases에서만 배포**합니다. GitLab 안내에서도 같은 다운로드 링크를 이용하세요.

## 처음 사용하는 순서

1. EXE를 실행해 설치하고 바탕화면의 **이수모아**를 엽니다.
2. 기관명과 관리자 계정을 직접 설정합니다.
3. **직원 명단 → 일괄 등록 → 빈 양식 다운로드**로 받은 엑셀을 채워 올립니다.
4. **교육 기준**의 기본 교육 16개와 연간 시간을 기관 지침에 맞게 확인합니다. 개인정보보호 기본값은 연 1시간입니다.
5. PDF·사진 수료증 또는 이들을 모은 ZIP을 올리고, **검수함**에서 원본과 직원·교육·날짜·시간·증서번호를 대조해 확정합니다.
6. **이수 현황**을 확인한 뒤 현황 엑셀·합본 PDF·수료증 ZIP·기관 제출 양식을 받습니다.

[전체 사용설명서](https://github.com/MuyeongKim/isumoa/blob/main/docs/사용설명서.md)에서 화면별 조작 방법을 확인할 수 있습니다.

## 주요 기능과 0.5.5 변경 사항

- 직원 엑셀 템플릿 일괄 등록, 부서·직원·교육 기준의 선택 삭제와 복원
- PDF·사진·ZIP 수료증 업로드와 쪽별 판독, 중복·주제 충돌 확인
- 검수함의 직원·교육명·파일명 검색, 여러 건 선택 제외, 검수 대기 초기화
- 개인별 합본 PDF 제목, 개별 수료증 ZIP의 공통 파일명 규칙·ZIP 제목 입력
- 등록한 교육별 **16시트 기관보고 양식 전체 출력**, 부서별 파일 분리, 다운로드 오류 안내
- 국립통일교육원 공식 공공과정 **47개**의 과정명·발급기관·2026년 대조. 안보교육 오연결의 확정을 차단하고, 다른 기관의 동명 과정·깨진 제목·개설 예정·마이크로러닝은 자동 연결하지 않고 검수 대상으로 남깁니다.
- 수료증 시간은 유지하고 공식 과정표와 다르면 경고합니다. 차시를 시간으로 바꾸지 않으며 기존 확정 이수기록은 자동 변경하지 않습니다.

최종 제출 명단(16시트)과 같은 형식으로 등록한 기관보고 양식은 선택 범위의 적용 교육을 모두 충족하고 검수 대기가 없어야 출력됩니다. 현원은 빈칸이며, 같은 직원의 여러 증서는 각각 기록하되 이수 인원은 한 명으로 계산합니다.

## 업데이트와 자료 보관

- **0.5.0 이상:** 설정 → 업데이트에서 새 버전 확인·다운로드·설치를 진행하거나 최신 EXE를 직접 실행합니다.
- **0.4.3 이하:** 최신 EXE를 직접 실행해 한 번 업데이트하세요.
- 업데이트 전 **설정 → 백업·보관 → 지금 백업**이 정상 완료되는지 확인하세요. 기존 기관 정보·직원·수료증과 사용자 지정 교육 기준은 유지합니다.
- 백업은 다른 디스크에도 보관하세요. 원본·DB·백업은 앱 자체에서 자동 암호화하지 않으므로 PC와 백업 접근 권한을 관리해야 합니다.

업데이트 확인·다운로드에는 GitHub 인터넷 연결이 필요합니다. 사진·스캔본은 글자를 잘못 읽을 수 있으므로 원본과 대조한 뒤 확정하세요.

## 검증과 시범운용 범위

0.5.5 소스의 **자동검증 424개·타입 검사**, 설치파일 추출·구성요소·업로드 체크섬 검증을 통과했습니다. 기관보고 양식은 재등록·다운로드·16시트 구조 검사와 macOS Numbers 실제 열기를 확인했습니다.

**미서명 부서 시범운용용**입니다. Windows 실기기 설치·실제 업데이트·Windows Excel/한셀 열기·인쇄·기관 백신 검사는 별도 미확인입니다. 먼저 시험용 PC와 복사한 자료로 [릴리스 검증 요약](https://github.com/MuyeongKim/isumoa-releases/releases/download/v0.5.5/validation-report-0.5.5.md)의 항목을 확인하세요.
