# 공식 검수 규칙

이수모아 0.5.8 이상: 설정 → 검수 규칙 → 최신 공식 규칙 확인을 사용합니다.
인터넷이 없는 PC는 latest.json을 다운로드해 가져옵니다. 서명·체크섬·호환 버전을 검사하고 변경 미리보기 후 적용합니다. 개인이 편집한 JSON은 사용자 규칙으로 별도 보관합니다.

2026.10.31.2: 국립통일교육원 공개 과정 47개와 기존 공통 연결 4개를 유지하고, 이수일 항목의 ‘이수완료일자’ 이름을 추가했습니다. 기관 교육 기준이나 확정 수료증은 변경하지 않습니다. 규칙 파일에는 직원·기관 업무 자료가 없습니다.

개인키는 공개하거나 설치판에 포함하지 않습니다. OCR 엔진·앱 보안 변경은 EXE 업데이트가 필요합니다.
